# Triage from the Compressed Latent

Code and machine-readable results for the paper **"Triage from the Compressed Latent:
Bandwidth-Constrained Telepathology with Delay-Tolerant Delivery."**

An integrated telepathology pipeline for rural, low-bandwidth settings: a benign/malignant
**triage decision is read directly from the ~5 KB compressed latent** of a learned image
codec (without reconstruction), used to prioritise malignant cases over a delay-tolerant
(store-and-forward) link. Everything is evaluated **patient-wise** on BreakHis (leakage-free)
with external validation on BACH.

> **Reproducibility note.** Every table and figure in the paper maps to one script and one
> result file (see the table below). All reported numbers are computed by these scripts; no
> value is hand-entered.

## Repository layout

```
*.py                     experiment, training, and figure scripts
theone/                  The ONE (DTN simulator) configuration files (Table 12)
results/*.json           machine-readable results (every reported number)
results/figures/*.png    generated figures
models/                  place trained weights here (see models/README_WEIGHTS.md)
paper/                   final manuscript PDF + response-to-reviewer letter
```

## Setup

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### Data (download separately — public datasets)
- **BreakHis** (breast histopathology): https://web.inf.ufpr.br/vri/databases/breast-cancer-histopathological-database-breakhis/
  Arrange as `BreakHis_8class/<subtype>/*.png` (use `prepare_breakhis.py`), with the official
  patient-wise folds in `archive/Folds.csv`.
- **BACH / ICIAR-2018** (external validation): https://iciar2018-challenge.grand-challenge.org/Dataset/
  Class folders `{Normal, Benign, InSitu, Invasive}` under a `Photos/` directory.

### Trained weights
Not stored in git (>100 MB). See [`models/README_WEIGHTS.md`](models/README_WEIGHTS.md) to
download them, or regenerate with the training scripts.

## Reproducing the paper

Each result file under `results/` is (re)generated by the script shown here. Paths to the
datasets are passed with `--data` / `--folds` / `--bach`.

| Paper item | Script | Result file |
|---|---|---|
| Classification, per-magnification (Tbl 3–5) | `train.py` | `kfold_results*.json`, `classification_report.txt` |
| Leakage ablation (Tbl 6, +45.8 pts) | `imagewise_ablation.py` | `imagewise_results.json` |
| Hierarchical negative result | `train_hierarchical.py` | `hierarchical_results.json` |
| Rate–distortion codecs (Tbl 8, Fig 6) | `compare_compression.py`, `train_compression_v2.py`, `train_hyperprior_pure.py` | `compression_comparison.json`, `learned_codec_results.json`, `hyperprior_results.json` |
| Triage from latent (Tbl 9) | `classify_from_latent.py` | `latent_classification_results.json` |
| Diagnosis-vs-bytes (§5.3) | `diagnose_vs_bytes.py` | `diagnose_vs_bytes.json` |
| Measured latent sensitivity r (Tbl 13) | `emit_latent_confusion.py` | `latent_confusion.json` |
| Hyperprior-latent triage (§5.2) | `triage_from_hyperprior_latent.py` | `hyperprior_latent_triage.json` |
| Edge encoder latency (§5.2) | `edge_latency.py` | `edge_latency.json` |
| Latent UMAP (Fig 10) | `latent_umap.py` | `latent_umap.json` |
| Network conditions / overhead (Tbl 10–11) | `benchmark_network.py` | `network_results*.json` |
| Wire-level DTN in The ONE (Tbl 12) | `theone/telepathology_settings.txt` | `theone_results.json` |
| Realistic triage speed-up (Tbl 13) | `realistic_triage_sim.py` | `realistic_triage_results.json` |
| Promote-only queueing sim (Tbl 14) | `queue_sim.py` | `queue_sim_results.json` |
| Promotion-threshold τ sweep (Fig 11) | `tau_sweep.py` | `tau_sweep.json` |
| Synthetic WSI (Tbl 15) | `synthetic_wsi_sim.py` | `synthetic_wsi_results.json` |
| External validation, BACH (Tbl 16) | `eval_external_bach.py` | `external_bach_results.json` |
| Domain adaptation / fine-tune (Tbl 16) | `finetune_bach.py` | `bach_finetune_results.json` |
| Imbalanced fine-tune (§5.8) | `finetune_bach_imbalanced.py` | `bach_finetune_imbalanced.json` |
| BACH threshold recalibration (§5.8) | `recalibrate_bach_threshold.py` | `bach_threshold_recal.json` |
| Macenko stain-norm test (§5.8) | `bach_stain_macenko.py` | `bach_stain_macenko.json` |
| Reconstruction figure (Fig 7) | `make_reconstruction_figure.py` | `results/figures/fig_reconstruction.png` |

Example:
```bash
python emit_latent_confusion.py --data path/to/BreakHis_8class \
    --folds path/to/archive/Folds.csv --codec-lambda 0.01 --epochs 20
```

The wire-level DTN metrics (Table 12) are produced by [The ONE](https://akeranen.github.io/the-one/)
using the configs in `theone/` (see `theone/README_THEONE.md`).
